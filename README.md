# 生まれてから何日？

公開URL：https://umarete-kara-29.vercel.app/

誕生日を入れるだけで、生まれてからの日数、心臓が動いた回数、地球と一緒に旅した距離、次の記念日（生誕◯000日・ゾロ目の日・誕生日）がわかるWebアプリ。結果はシェア用の画像にしてXやストーリーに投稿できます。

誕生日はブラウザの中だけで計算し、どこにも送信・保存しません。

## ファイル

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML・CSS・JSを1ファイルに収録） |
| `og.png` | SNSでリンクを貼ったときに出るプレビュー画像 |
| `icon.svg` / `icon-*.png` | ブラウザのタブとホーム画面のアイコン |
| `manifest.webmanifest` | スマホの「ホーム画面に追加」用の設定 |
| `vercel.json` | Vercelの配信設定（画像のキャッシュなど） |

## Vercelで公開する

1. https://vercel.com に GitHub アカウントでログイン
2. 「Add New…」→「Project」で、このリポジトリを Import
3. Framework Preset は「Other」のまま、何も変えずに Deploy
4. 以降は GitHub にプッシュするたびに自動で更新される

## 計算の目安

心拍は1分80回、呼吸は1分16回、まばたきは起きている間1分15回、睡眠は1日8時間、食事は1歳から1日3回として計算しています。
